# TronClass 自動辨識學期同步（Chrome 配套擴充功能）

每 30 分鐘在已登入的 Chrome 中讀取東吳 TronClass，先讀取課程、學期和學年 ID 對照資訊，再確認**目前學期**，再只抓取該學期**未繳交**的作業活動，送入時間管理網站的「偵測到的作業／考試」清單。115-1 → 115-2 → 116-1 會依學期自動切換，不必每學期改程式。

## 更新安裝（v0.4.0）

1. 將新版 ZIP 解壓縮，保留 `tronclass-extension` 資料夾。
2. 在 Chrome 的 `chrome://extensions/` 移除舊版，按「載入未封裝項目」選新版資料夾。
3. 在同一個 Chrome 登入 <https://tronclass.scu.edu.tw/>，確認可以看到課程，接著點擴充功能圖示立即同步。
4. 登入 <https://time-management.5f6g5w9r9m.workers.dev/>，重新整理頁面，選「更多工具 → TronClass 作業／考試」查看本學期資料。

## 學期與資料規則

- 學期是**先用台北時間判斷當期學年度**（一般 8–1 月為第 1 學期、2–7 月為第 2 學期），再用 TronClass **課程 metadata 的學年度和學期**驗證；並非只靠截止日期猜課程屬哪個學期。
- 如果學校開學、結束時間與上述月份不完全一致，可能暫時顯示無法辨識。**無法確認就停止同步，保留舊資料，不抓其他學期充數。**
- 明確已繳交作業不列入；未知提交狀態會標為「待確認」，而非冒稱未繳。
- 每個學科可在「學科管理 → TronClass 作業」選擇相符課程。
- 課程活動以課程 ID + 活動 ID 去重，同步資料只顯示當前學期；已經**手動加入時間管理的任務／考試**不會因為換學期遭刪除。
- 來源課程內的「作業」活動可抓取；只有寫在公告、附件或獨立線上測驗的考試，不一定能自動抓到。若項目實際是考試，請核對**真正考試日期與時間**，再選「考試」加入。
- 登入只沿用 Chrome 原本的 TronClass 工作階段，不會讀取或儲存學校密碼及 Cookie 值。

## 限制

- Chrome 必須開啟且學校登入有效，才會定期同步；**關機後不會繼續在雲端執行**。
- 未在東吳所有學期回傳格式實測；校方更新學期欄位可能需要調整。失敗時顯示錯誤，不清除已儲存的任務。
- 同步讀取的作業資料暫存於本機 Chrome 擴充功能，開啟且登入時間管理網站時才寫進私人 Cloudflare D1。
- 請遵守校方對自動存取的規範；若校方不允許，請停用。
