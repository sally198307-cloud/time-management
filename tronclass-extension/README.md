# TronClass 自動同步（Chrome 配套擴充功能）

這個擴充功能每 30 分鐘嘗試讀取東吳 TronClass **目前進行中課程**的作業清單，並將作業名稱、課程、截止時間和狀態送進原本「時間管理」網站的 **待確認** 清單。你可以自行選擇是否加入任務；不會自動提交作業、修改成績或把已繳交誤當成已完成。

## 安裝

1. 下載整個 `time-management` 專案的 ZIP，解壓縮。
2. 使用電腦版 Chrome 開啟 `chrome://extensions/`，開啟右上角「開發人員模式」。
3. 點選「載入未封裝項目」，選取解壓縮後的 `tronclass-extension` 資料夾。
4. 在同一個 Chrome 登入 <https://tronclass.scu.edu.tw/>，確認能看到「我的課程」。
5. 開啟 <https://time-management.5f6g5w9r9m.workers.dev/>，從「更多工具 → TronClass 課務同步」檢查同步狀態。
6. 第一次可點 Chrome 工具列上的擴充功能圖示，立即執行同步。之後每 30 分鐘會再試一次。

若 TronClass 登入過期，擴充功能會顯示 `!`，請手動登入學校網站後點圖示重試。登入期間使用的 Cookie 由 Chrome 原本的 TronClass 分頁管理；擴充功能**不讀取或儲存帳號密碼和 Cookie 值**。

## 限制與安全

- 只有 **Chrome 開著且 TronClass 仍是已登入狀態** 才能定期讀取，**不是**電腦關機後仍可執行的雲端排程。
- 首次同步可能短暫開啟一個背景 TronClass 分頁。登入失效時不會自動嘗試密碼或繞過驗證碼。
- 資料端點參考非官方 API 程式碼；**尚未在使用者真實的東吳登入帳戶測試**。若學校改版，擴充功能會顯示錯誤並保留上次成功的資料。
- 擷取範圍是 TronClass 課程內的「作業」活動，不含只寫在公告、附件、LINE 的任務或線上測驗；這些仍需人工確認。
- 登入的作業資料會先存放在此 Chrome 的擴充功能本機儲存空間，當你開啟時間管理網站時才寫入原本 Cloudflare D1 的網站資料。擴充功能不會把資料傳給其他網站。
- 同步時請遵守學校對自動存取的使用規範。如果校方不允許此方式，請停用擴充功能並保留原本的手動匯入。

## 資料更新規則

- 作業以 `課程 ID + 活動 ID` 去重，不以名稱做唯一識別。
- 截止時間或名稱變更時重新標記「待確認」，已加入的任務不會直接改動。
- 不足的截止時間留空，**不猜測**截止日期。
- 每個學科可在「學科管理 → TronClass 作業」選擇要對應的 TronClass 課程。
- 你手動修改過的任務名稱、分類、子任務、完成狀態都會保留。
